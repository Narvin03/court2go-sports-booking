# Court2Go – Sports Venue Booking System

Court2Go is a web-based sports venue booking platform developed using PHP, MySQL, JavaScript, HTML, and CSS.

## Features

- User registration and login
- Sports venue browsing
- Venue search and filtering
- Online venue booking
- Booking cancellation
- User favourites
- Promotions and discounts
- User profile management
- Payment and receipt generation
- Password reset

## Technologies Used

- PHP
- MySQL
- JavaScript
- HTML
- CSS
- XAMPP

## Project Structure

- `Assets/` – Images and other media
- `Includes/` – Header, footer, and navigation components
- `JavaScripts/` – Client-side scripts
- `Styles/` – CSS files
- `php/` – Backend PHP processing files
- `phpmailer/` – Email functionality
- `db.sql` – Database structure and sample data

## Installation

1. Clone this repository.
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Import `db.sql` into MySQL using phpMyAdmin.
5. Open the project through localhost.
